# Oasis Infobyte Data Science Internship (OIBSIP)

Welcome to the official repository for the **Oasis Infobyte Data Science Internship (OIBSIP)** projects. This repository contains end-to-end data analysis, exploratory data analysis (EDA), machine learning models, evaluations, and visualizations across 4 key Data Science domain tasks.

---

## 📌 Task Overview

| Task # | Project Name | Description | Key Tech / Algorithms | Folder Path |
|---|---|---|---|---|
| **Task 1** | **Iris Flower Classification** | Multi-class classification of Iris flower species based on sepal and petal measurements. | Logistic Regression, Random Forest, Decision Tree, KNN, Seaborn | [`DataScience-Task1-IrisClassification/`](./DataScience-Task1-IrisClassification/) |
| **Task 2** | **Unemployment Analysis with Python** | Regional and temporal trend analysis of Indian unemployment rates before and during COVID-19. | Pandas, Seaborn, Matplotlib, Pre/Post COVID Comparison | [`DataScience-Task2-UnemploymentAnalysis/`](./DataScience-Task2-UnemploymentAnalysis/) |
| **Task 3** | **Car Price Prediction** | Supervised regression task to predict used car selling prices with feature engineering. | Linear Regression, Random Forest Regressor, Gradient Boosting | [`DataScience-Task3-CarPricePrediction/`](./DataScience-Task3-CarPricePrediction/) |
| **Task 4** | **Email Spam Detection** | Natural Language Processing (NLP) pipeline & text classification for spam detection. | NLTK, TF-IDF Vectorizer, Multinomial Naive Bayes, Logistic Regression | [`DataScience-Task4-EmailSpamDetection/`](./DataScience-Task4-EmailSpamDetection/) |

## 💻 Tech Stack & Requirements

- **Language**: Python 3.10+
- **Data Manipulation**: `pandas`, `numpy`
- **Data Visualization**: `matplotlib`, `seaborn`
- **Machine Learning**: `scikit-learn`
- **Natural Language Processing**: `nltk`
- **Notebook Environment**: `jupyter`, `nbformat`, `nbconvert`

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone git@github.com:zakiaabdalla59-dev/OIBSIP.git
cd OIBSIP
```

### 2. Set Up Virtual Environment & Dependencies
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pandas numpy scikit-learn matplotlib seaborn nltk jupyter
```

### 3. Run Jupyter Notebooks
```bash
jupyter notebook
```
Navigate to any task directory and open the corresponding `.ipynb` file to view or re-run code cells.
